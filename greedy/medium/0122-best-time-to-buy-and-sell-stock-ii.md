> [!NOTE]
> **Problem Statement**
>
> You are given an integer array prices where prices[i] is the price of a given stock on the ith day.
>
> **[→ Open on LeetCode](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-ii/)**

<br>

### Solution

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        int profit = 0;
        for(int i = 1;i<n;i++){
            if(prices[i]>=prices[i-1]){
                profit+=(prices[i]-prices[i-1]);
            }
        }
        return profit;
    }
};
```

<br>

### Approach

> The solution uses a greedy approach, iterating through the array of stock prices and adding the difference between consecutive prices to the total profit whenever the price increases. This approach takes advantage of the fact that we can buy and sell the stock multiple times, allowing us to accumulate profit from every upward trend in the prices. The key idea is to keep adding the positive differences to the total profit, effectively simulating the process of buying and selling the stock at the right times. By doing so, we ensure that we capture all possible opportunities to make a profit.
