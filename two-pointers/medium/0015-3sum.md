> [!NOTE]
> **Problem Statement**
>
> Given an integer array nums, return all the triplets [nums[i], nums[j], nums[k]] such that i != j, i != k, and j != k, and nums[i] + nums[j] + nums[k] == 0.
> 
> Notice that the solution set must not contain duplicate triplets.
> 
>  
> Example 1:
> 
> Input: nums = [-1,0,1,2,-1,-4]
> Output: [[-1,-1,2],[-1,0,1]]
> Explanation: 
> nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0.
> nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0.
> nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0.
> The distinct triplets are [-1,0,1] and [-1,-1,2].
> Notice that the order of the output and the order of the triplets does not matter.

### Solution (C++)

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        int n = nums.size();
        sort(nums.begin(),nums.end());
        vector<vector<int>>ans;
        for(int i=0;i<n;i++){
            if(i!=0&&nums[i]==nums[i-1])continue;
            int Target = 0-nums[i];
            int left=i+1;
            int right=n-1;

            while(left<right){
                if(nums[left]+nums[right]==Target){
                    ans.push_back({nums[i],nums[left],nums[right]});
                    int temp1=nums[left];
                    int temp2=nums[right];
                    while(temp1==nums[left]&&left<right){
                        left++;
                    }
                    while(temp2==nums[right]&&left<right){
                        right--;
                    }
                   
                }
                else if(nums[left]+nums[right]<Target){
                   left++;
                }
                else {
                    right--;
                }
            }

        } 
        return ans;
    }
};
```

<br>

### Approach

> First, sort the array to enable efficient searching and easy duplicate handling. Iterate through the array with a fixed pointer `i`, skipping duplicates to ensure unique triplets. For each `i`, use two pointers, `left` and `right`, to find pairs that sum to the negative of `nums[i]`. Adjust the pointers inward based on whether the current sum is less than or greater than the target, and skip duplicates when a valid triplet is found.

<details>
<summary><strong>Why It Works (Click to expand)</strong></summary>
<br>

> Sorting the array ensures that the two-pointer technique can systematically explore all possible pairs for a fixed element without missing any valid combinations. By skipping duplicate values at each step, the algorithm guarantees that only unique triplets are added to the result set.

</details>

### Complexity

| Bound | Explanation |
|:--|:--|
| **Time:** `O(n^2)` | because the outer loop runs n times and the inner two-pointer loop runs in O(n) time for each iteration. |
| **Space:** `O(1)` | excluding the output array, as the algorithm uses only a constant amount of extra space for pointers and variables. |
