> [!NOTE]
> **Problem Statement**
>
> Given an integer array nums, return all the triplets [nums[i], nums[j], nums[k]] such that i != j, i != k, and j != k, and nums[i] + nums[j] + nums[k] == 0.
> 
> Notice that the solution set must not contain duplicate triplets.
> 
>  
> Example 1:
> 
> Input: nums = [-1,0,1,2,-1,-4]
> Output: [[-1,-1,2],[-1,0,1]]
> Explanation: 
> nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0.
> nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0.
> nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0.
> The distinct triplets are [-1,0,1] and [-1,-1,2].
> Notice that the order of the output and the order of the triplets does not matter.

### Solution (C++)

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        int n = nums.size();
        sort(nums.begin(),nums.end());
        vector<vector<int>>ans;
        for(int i=0;i<n;i++){
            if(i!=0&&nums[i]==nums[i-1])continue;
            int Target = 0-nums[i];
            int left=i+1;
            int right=n-1;

            while(left<right){
                if(nums[left]+nums[right]==Target){
                    ans.push_back({nums[left],nums[right],nums[i]});
                    int temp1=nums[left];
                    int temp2=nums[right];
                    while(temp1==nums[left]&&left!=right){
                        left++;
                    }
                    while(temp2==nums[right]&&left!=right){
                        right--;
                    }
                   
                }
                else if(nums[left]+nums[right]<Target){
                    int temp = nums[left];
                    while(left!=right&&nums[left]==temp){
                        left++;
                    }
                }
                else {
                    int temp = nums[right];
                    while(left!=right&&nums[right]==temp){
                        right--;
                    }
                }
            }

        } 
        return ans;
    }
};
```

### Approach

> First sort the array so equal values become adjacent. Then iterate each index i as the first element of a potential triplet, skipping duplicates. For each i, set two pointers: left at i+1 and right at the end of the array, and move them inward to find pairs whose sum equals -nums[i]. Whenever a valid triplet is found, record it and advance both pointers past any duplicate values to avoid repeated results.

<details>
<summary><strong>Why It Works (Click to expand)</strong></summary>
<br>

> Because the array is sorted, increasing the left pointer raises the sum while decreasing the right pointer lowers it, guaranteeing that all combinations are examined without missing any. Skipping equal values at each step ensures each unique triplet is produced exactly once.

</details>

### Complexity

| Bound | Explanation |
|:--|:--|
| **Time:** `O(n^2)` | the outer loop runs O(n) times and the inner two‑pointer scan runs O(n) for each iteration, giving quadratic time. |
| **Space:** `O(1)` | extra space (ignoring the output list) since only a few indices and temporary variables are used. |

<br>

> [!TIP]
> **Key Insight**
> 
> Sorting lets the two‑pointer technique turn the 3‑sum problem from cubic to quadratic by turning the inner search into a linear scan.

<br>

> [!IMPORTANT]
> **Pattern to Remember**
>
> Sort the data then use a two‑pointer sweep inside a loop to solve pair‑sum subproblems efficiently.
