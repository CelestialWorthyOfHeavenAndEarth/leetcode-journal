> [!NOTE]
> **Problem Statement**
>
> Given a non-empty array of integers nums, every element appears twice except for one. Find that single one.
>
> **[→ Open on LeetCode](https://leetcode.com/problems/single-number/)**

<br>

### Solution

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        unordered_map<int , int> freq;
        for(int i:nums){
            freq[i]++;
        }
        for(int i:nums){
            if(freq[i]==1){
                return i;
            }
        }
        return -1;
    }
};
```

<br>

### Approach

> The solution uses an unordered map to store the frequency of each number in the array. It iterates over the array to count the occurrences of each number and stores them in the map. Then, it iterates over the array again to find the number with a frequency of 1. This approach works because the problem guarantees that every element appears twice except for one. The solution returns the single number as soon as it finds it.
