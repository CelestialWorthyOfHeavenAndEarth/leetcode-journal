> [!NOTE]
> **Problem Statement**
>
> Given the array nums consisting of 2n elements in the form [x1,x2,...,xn,y1,y2,...,yn].
>
> **[→ Open on LeetCode](https://leetcode.com/problems/shuffle-the-array/)**

<br>

### Solution

```cpp
class Solution {
public:
    vector<int> shuffle(vector<int>& nums, int n) {

        vector<int>ans; 
        for(int i=0;i<nums.size()/2;i++){
            ans.push_back(nums[i]);
            ans.push_back(nums[n+i]);
        }
        return ans;
    }
};
```

<br>

### Approach

> The solution uses a simple iterative approach to create a new array by alternating elements from the first and second halves of the input array. It starts by initializing an empty vector to store the shuffled array. Then, it iterates over the first half of the input array, appending each element and its corresponding element from the second half to the result vector. This process effectively shuffles the array as required. The solution assumes that the input array is well-formed and has an even number of elements.

> This approach works because it correctly alternates elements from the two halves of the input array, resulting in the desired shuffled array. The use of the index `n+i` ensures that the corresponding elements from the second half are appended to the result vector. The solution handles the array in a straightforward and efficient manner.

### Complexity

| Bound | Explanation |
|:--|:--|
| **Time:** `O(n)` | The solution has a linear time complexity because it only needs to iterate over the first half of the input array once. |
| **Space:** `O(n)` | The solution has a linear space complexity because it creates a new array of the same size as the input array. |
