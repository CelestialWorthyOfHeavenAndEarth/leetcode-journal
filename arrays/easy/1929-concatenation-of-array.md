> [!NOTE]
> **Problem Statement**
>
> Given an integer array nums of length n, you want to create an array ans of length 2n where ans[i] == nums[i] and ans[i + n] == nums[i] for 0 <= i < n (0-indexed).
>
> **[→ Open on LeetCode](https://leetcode.com/problems/concatenation-of-array/)**

<br>

### Solution

```cpp
class Solution {
public:
    vector<int> getConcatenation(vector<int>& nums) {
        int n = nums.size();
        vector <int> ans(2*n);
        for(int i=0;i<n;i++){
            ans[i]=nums[i];
            ans[i+n]=nums[i];
        }
        return ans;
    }
};
```

<br>

### Approach

> The approach to solving this problem involves creating a new array that is twice the size of the input array. We then iterate over the input array, copying each element to its corresponding position in the new array, as well as to the position that is offset by the length of the input array. This effectively creates a concatenated version of the input array. By using a simple loop to perform the copying, we can efficiently create the desired output array.

The loop ensures that each element is correctly placed in the output array. The result is a new array that meets the specified conditions.

| **Space:** `O(n)` | because we are creating a new array that is twice the size of the input array. |
