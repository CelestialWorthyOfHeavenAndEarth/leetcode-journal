> [!NOTE]
> **Problem Statement**
>
> Given an integer array nums, return true if any value appears at least twice in the array, and return false if every element is distinct.
>
> **[→ Open on LeetCode](https://leetcode.com/problems/contains-duplicate/)**

<br>

### Solution

```cpp
class Solution {
public:
    bool containsDuplicate(vector<int>& nums) {
        unordered_map<int, int>freq;
        for(int x:nums){
            freq[x]++;
            if(freq[x]>1){
                return true;
            }
        }
        return false;
    }
};
```

<br>

### Approach

> The solution utilizes an unordered map to store the frequency of each element in the array. It iterates through the array, incrementing the count of each element in the map. If an element's count exceeds 1, it immediately returns true, indicating a duplicate. This approach allows for efficient detection of duplicates without requiring sorting or complex comparisons. By using an unordered map, the solution can handle large arrays with minimal overhead.

> The solution works because it keeps track of the frequency of each element, allowing it to detect duplicates as soon as they occur. The unordered map provides constant-time lookups and insertions, making the solution efficient. This approach ensures that the solution returns true as soon as it encounters a duplicate, and false otherwise.

### Complexity

| Bound | Explanation |
|:--|:--|
| **Time:** `O(n)` | , where n is the number of elements in the array, because it makes a single pass through the array. |
| **Space:** `O(n)` | , where n is the number of unique elements in the array, because in the worst case, it needs to store every element in the unordered map. |
