### Approach

> The approach to solve this problem involves iterating through the given sorted array and keeping track of the last non-duplicate element found. We can use two pointers, one for reading the array and one for writing the unique elements. As we iterate through the array, if the current element is different from the last non-duplicate element, we update the last non-duplicate element and write it to the next available position. This process continues until we have iterated through the entire array. By doing so, all unique elements will be moved to the front of the array in the same order as they appeared in the original array.

> This approach works because the input array is already sorted, which allows us to easily identify duplicates by comparing adjacent elements. By maintaining a separate pointer for writing unique elements, we can ensure that each unique element appears only once in the resulting array.
