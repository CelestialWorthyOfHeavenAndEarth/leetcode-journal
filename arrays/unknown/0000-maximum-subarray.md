> ### 💡 Key Insight
>
> The key insight is to reset the current sum to zero when it becomes negative, which allows the algorithm to efficiently find the maximum subarray sum.

<br>

> [!TIP]
> ### 🧠 Approach & Explanation
>
> The solution uses Kadane's algorithm, which iterates through the array and at each step, it decides whether to include the current element in the subarray or start a new subarray. It keeps track of the maximum sum seen so far and the current sum. If the current sum becomes negative, it resets the current sum to zero, effectively starting a new subarray. This approach allows the algorithm to efficiently find the maximum subarray sum. The algorithm iterates through the array only once, making it efficient for large inputs.
>
> <details>
> <summary><strong>⚙️ Why It Works (Click to expand)</strong></summary>
>
> The algorithm works because it considers all possible subarrays and keeps track of the maximum sum seen so far. By resetting the current sum to zero when it becomes negative, the algorithm avoids including negative sums in the subarray, which would decrease the overall sum. This ensures that the algorithm finds the maximum subarray sum.
>
> </details>

### 💻 Implementation

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int n = nums.size();
        int bag=0;
        int max_seen= INT_MIN;
        for(int i=0;i<n;i++){
            bag+=nums[i];
            if(bag>max_seen){
                max_seen=bag;
            }
            if(bag<0){
                bag=0;
            }
        }
        return max_seen;
    }
};
```
