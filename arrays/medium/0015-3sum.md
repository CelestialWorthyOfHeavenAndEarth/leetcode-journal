> [!NOTE]
> **Problem Statement**
>
> Given an integer array nums, return all the triplets [nums[i], nums[j], nums[k]] such that i != j, i != k, and j != k, and nums[i] + nums[j] + nums[k] == 0.
> 
> Notice that the solution set must not contain duplicate triplets.
> 
>  
> Example 1:
> 
> Input: nums = [-1,0,1,2,-1,-4]
> Output: [[-1,-1,2],[-1,0,1]]
> Explanation: 
> nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0.
> nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0.
> nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0.
> The distinct triplets are [-1,0,1] and [-1,-1,2].
> Notice that the order of the output and the order of the triplets does not matter.

### Solution (C++)

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        int n = nums.size();
        sort(nums.begin(),nums.end());
        vector<vector<int>>ans;
        for(int i=0;i<n;i++){
            if(i!=0&&nums[i]==nums[i-1])continue;
            int Target = 0-nums[i];
            int left=i+1;
            int right=n-1;

            while(left<right){
                if(nums[left]+nums[right]==Target){
                    ans.push_back({nums[i],nums[left],nums[right]});
                    int temp1=nums[left];
                    int temp2=nums[right];
                    while(temp1==nums[left]&&left<right){
                        left++;
                    }
                    while(temp2==nums[right]&&left<right){
                        right--;
                    }
                   
                }
                else if(nums[left]+nums[right]<Target){
                    int temp = nums[left];
                    while(left<right&&nums[left]==temp){
                        left++;
                    }
                }
                else {
                    int temp = nums[right];
                    while(left<right&&nums[right]==temp){
                        right--;
                    }
                }
            }

        } 
        return ans;
    }
};
```

### Approach

> First sort the array so that equal values are adjacent. Then iterate through each element as a potential first member of a triplet. For each fixed element, use two pointers—one starting just after it and one at the end—to find pairs that sum to the negative of the fixed element. Whenever a pair is found, record the triplet and advance both pointers past any duplicates to avoid repeated results. Repeat until all elements have been considered.

<details>
<summary><strong>Why It Works (Click to expand)</strong></summary>
<br>

> Sorting guarantees that moving the left pointer to the right increases the sum and moving the right pointer to the left decreases it, so the two‑pointer scan correctly explores all complementary pairs. Skipping duplicates at each step preserves the invariant that each unique triplet is added exactly once.

</details>

<br>

### Complexity

| Bound | Explanation |
|:--|:--|
| **Time:** `O(n^2)` | sorting takes O(n log n) and the nested two‑pointer scan runs in O(n) for each of the n elements. |
| **Space:** `O(1)` | aside from the output list, only a few integer variables are used; the algorithm modifies the input array in place. |

<br>

> [!TIP]
> **Key Insight**
> 
> Sorting + two pointers turns a cubic search into a quadratic one by turning the sum check into a monotonic walk.

<br>

> [!IMPORTANT]
> **Pattern to Remember**
>
> Use two pointers after sorting to find pairs that complement a fixed element.
