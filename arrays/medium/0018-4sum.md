> [!NOTE]
> **Problem Statement**
>
> Given an array nums of n integers, return an array of all the unique quadruplets [nums[a], nums[b], nums[c], nums[d]] such that:
> 
> 
> 	0 <= a, b, c, d < n
> 	a, b, c, and d are distinct.
> 	nums[a] + nums[b] + nums[c] + nums[d] == target
> 
> 
> You may return the answer in any order.
> 
>  
> Example 1:
> 
> Input: nums = [1,0,-1,0,-2,2], target = 0
> Output: [[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]
> 
> 
> Example 2:
> 
> Input: nums = [2,2,2,2,2], target = 8
> Output: [[2,2,2,2]]
> 
> 
>  
> Constraints:
> 
> 
> 	1 <= nums.length <= 200
> 	-109 <= nums[i] <= 109
> 	-109 <= target <= 109
>
> **[→ Open on LeetCode](https://leetcode.com/problems/4sum/)**

### Solution (C++)

```cpp
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        int n=nums.size();
        vector<vector<int>>ans;
        sort(nums.begin(),nums.end());
        for(int i=0;i<n;i++){
            if(i!=0&&nums[i]==nums[i-1])continue;
            for(int j=i+1;j<n;j++){
                if(j!=i+1&&nums[j]==nums[j-1])continue;
                long long Target=(long long)target-nums[i]-nums[j];
                int left=j+1;
                int right=n-1;
                while(left<right){
                    if(nums[left]+nums[right]==Target){
                        ans.push_back({nums[i],nums[j],nums[left],nums[right]});
                        int temp1=nums[left];
                        int temp2=nums[right];
                        while(left<right&&temp1==nums[left]){
                            left++;
                        }
                        while(left<right&&temp2==nums[right]){
                            right--;
                        }
                        
                    }
                    else if(nums[left]+nums[right]<Target){
                        left++;
                    }
                    else {
                        right--;
                    }
                }
            }
        }
        return ans;
    }
};
```

<br>

### Approach

> Sort the array first. Then use two nested loops to pick the first two numbers of a quadruplet. For each pair, use a two‑pointer scan on the remaining subarray to find the other two numbers that sum to the remaining target. Skip duplicate values after each selection to keep results unique.

<details>
<summary><strong>Why It Works (Click to expand)</strong></summary>
<br>

> Sorting guarantees that equal numbers are adjacent, so skipping duplicates removes repeated quadruplets. The two‑pointer scan maintains the invariant that the left pointer moves right when the sum is too small and the right pointer moves left when the sum is too large, ensuring all valid pairs are found.

</details>

<br>

### Complexity

| Bound | Explanation |
|:--|:--|
| **Time:** `O(n³)` | time – two loops (O(n²)) and a linear two‑pointer scan (O(n)) for each pair. |
| **Space:** `O(1)` | auxiliary space – only a few indices are used; the output list is not counted as extra space. |

<br>

> [!TIP]
> **Key Insight**
> 
> After fixing two numbers, the remaining two can be found in linear time with two pointers.

<br>

> [!IMPORTANT]
> **Pattern to Remember**
>
> Two‑pointer search on a sorted array after fixing outer indices.
