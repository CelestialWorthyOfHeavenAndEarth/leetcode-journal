> [!NOTE]
> **Problem Statement**
>
> You are given an integer array prices where prices[i] is the price of a given stock on the ith day.
> 
> On each day, you may decide to buy and/or sell the stock. You can only hold at most one share of the stock at any time. However, you can sell and buy the stock multiple times on the same day, ensuring you never hold more than one share of the stock.
> 
> Find and return the maximum profit you can achieve.
> 
>  
> Example 1:
> 
> Input: prices = [7,1,5,3,6,4]
> Output: 7
> Explanation: Buy on day 2 (price = 1) and sell on day 3 (price = 5), profit = 5-1 = 4.
> Then buy on day 4 (price = 3) and sell on day 5 (price...
>
> **[→ Open on LeetCode](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-ii/)**

### Solution (C++)

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        int profit = 0;
        for(int i = 1;i<n;i++){
            if(prices[i]>=prices[i-1]){
                profit+=(prices[i]-prices[i-1]);
            }
        }
        return profit;
    }
};
```

<br>

### Approach

> We iterate over the prices array and accumulate the profit whenever the current price is greater than or equal to the previous price. This ensures we only capture upward moves, effectively buying at each local minimum and selling at the next local maximum, which yields the maximum total profit.

<details>
<summary><strong>Why It Works (Click to expand)</strong></summary>
<br>

> By summing all positive differences between consecutive days, we capture every profitable transaction without missing any gain, which is optimal because any sequence of buys and sells can be decomposed into these incremental gains.

</details>

### Complexity

| Bound | Explanation |
|:--|:--|
| **Time:** `O(n)` | a single pass over the array computes the profit. |
| **Space:** `O(1)` | only a few integer variables are used regardless of input size. |

> [!TIP]
> **Key Insight**
> 
> All profitable trades can be represented as the sum of positive day‑to‑day price differences.

<br>

> [!IMPORTANT]
> **Pattern to Remember**
>
> Use a greedy scan to accumulate positive adjacent differences for unlimited‑transaction stock profit problems.
