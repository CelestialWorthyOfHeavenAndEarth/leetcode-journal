### How It Works

```
1. Solve a problem on LeetCode
2. Click "Save to Journal" in the browser extension
3. AI analyzes your solution (approach, complexity, key insight)
4. A structured note is committed to this repo under the topic folder
5. This README updates automatically with your progress
```
