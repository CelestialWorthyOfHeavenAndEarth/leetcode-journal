## Getting Started

```
1. Create a GitHub repository called leetcode-journal
2. Grab a free API key from console.groq.com
3. Get a GitHub Personal Access Token with repo scope
   (github.com/settings/tokens)
4. Load the extension in Chrome
   (chrome://extensions > Developer Mode > Load Unpacked)
5. Open any LeetCode problem, write your solution,
   and click Save to Journal
```
