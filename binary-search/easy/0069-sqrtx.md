> [!NOTE]
> **Problem Statement**
>
> Given a non-negative integer x, return the square root of x rounded down to the nearest integer. The returned integer should be non-negative as well.
> 
> You must not use any built-in exponent function or operator.
> 
> 
> 	For example, do not use pow(x, 0.5) in c++ or x ** 0.5 in python.
> 
> 
>  
> Example 1:
> 
> Input: x = 4
> Output: 2
> Explanation: The square root of 4 is 2, so we return 2.
> 
> 
> Example 2:
> 
> Input: x = 8
> Output: 2
> Explanation: The square root of 8 is 2.82842..., and since we round it down to the nearest integer, 2 is returned.
> 
> 
>  
> Constraints:
> 
> 
> 	0 <= x <= 231 - 1
>

### Approach

> We treat the square root as an unknown integer k such that k*k ≤ x < (k+1)*(k+1). Because the function f(k)=k*k is monotonic for non‑negative k, we can binary‑search the interval [0, x] (or [0, x/2+1] for x>1) to locate the largest k satisfying the condition. In each iteration we compute mid, compare mid*mid with x, and shrink the search range accordingly until low exceeds high. The final answer is the last valid mid (or high).

<details>
<summary><strong>Why It Works (Click to expand)</strong></summary>
<br>

> The invariant that the true floor‑sqrt lies within the current low‑high range is preserved because we discard only the half where the condition cannot hold. When the loop terminates, high is the greatest value whose square does not exceed x, which by definition is ⌊√x⌋.

</details>

### Complexity

| Bound | Explanation |
|:--|:--|
| **Time:** `O(log x)` | each iteration halves the search interval, leading to logarithmic steps. |
| **Space:** `O(1)` | only a few integer variables are used regardless of input size. |

> [!TIP]
> **Key Insight**
> 
> The monotonic nature of the square function lets us binary‑search the answer space instead of iterating linearly.

<br>

> [!IMPORTANT]
> **Pattern to Remember**
>
> Use binary search on a monotonic predicate to find the boundary value (the largest index satisfying a condition).
