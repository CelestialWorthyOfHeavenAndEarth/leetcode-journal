> [!NOTE]
> **Problem Statement**
>
> Given a non-negative integer x, return the square root of x rounded down to the nearest integer. The returned integer should be non-negative as well.
> 
> You must not use any built-in exponent function or operator.
> 
> 
> 	For example, do not use pow(x, 0.5) in c++ or x ** 0.5 in python.
> 
> 
>  
> Example 1:
> 
> Input: x = 4
> Output: 2
> Explanation: The square root of 4 is 2, so we return 2.
> 
> 
> Example 2:
> 
> Input: x = 8
> Output: 2
> Explanation: The square root of 8 is 2.82842..., and since we round it down to the nearest integer, 2 is returned.
> 
> 
>  
> Constraints:
> 
> 
> 	0 <= x <= 231 - 1
>
> **[→ Open on LeetCode](https://leetcode.com/problems/sqrtx/)**

<br>

### Solution (C++)

```cpp
class Solution {
public:
    int mySqrt(long int x) {
        long int ans;
        for(long int i=0;i*i<=x;i++ ){
            ans=i;
        }
        return ans;
    }
};
```

<br>

### Approach

> The algorithm iterates i from 0 upward, checking i*i against x. While i*i is less than or equal to x, it records i as the current answer. Once i*i exceeds x, the loop stops and the last recorded i is returned as the integer square root.

<details>
<summary><strong>Why It Works (Click to expand)</strong></summary>
<br>

> Because i increases monotonically, the loop maintains the invariant that ans is the greatest integer whose square does not exceed x. When the condition fails, no larger integer can satisfy i*i <= x, so ans is correct.

</details>

<br>

### Complexity

| Bound | Explanation |
|:--|:--|
| **Time:** `O(√x)` | the loop runs until i reaches roughly the square root of x, performing a constant amount of work each iteration. |
| **Space:** `O(1)` | only a few integer variables are used regardless of input size. |

<br>

> [!TIP]
> **Key Insight**
> 
> The integer square root is the largest i such that i*i ≤ x, so a simple linear scan up to √x suffices.

<br>

> [!IMPORTANT]
> **Pattern to Remember**
>
> Use a monotonic linear search when the predicate (i*i ≤ x) changes from true to false at the desired answer.
