> [!NOTE]
> **Problem Statement**
>
> Given an integer n, return true if it is a power of four. Otherwise, return false.
> 
> An integer n is a power of four, if there exists an integer x such that n == 4x.
> 
>  
> Example 1:
> Input: n = 16
> Output: true
> Example 2:
> Input: n = 5
> Output: false
> Example 3:
> Input: n = 1
> Output: true
> 
>  
> Constraints:
> 
> 
> 	-231 <= n <= 231 - 1
> 
> 
>  
> Follow up: Could you solve it without loops/recursion?
>
> **[→ Open on LeetCode](https://leetcode.com/problems/power-of-four/)**

<br>

### Solution (C++)

```cpp
class Solution {
public:
    bool isPowerOfFour(int n) {
        long int pow=1;
        for(int i=0;pow<n;i++){
            pow=pow*4;
        }
        if(pow==n){
            return true;
        }
        return false;
    }
};
```

<br>

### Approach

> The algorithm starts with 1 and repeatedly multiplies by 4 until the value is no longer less than the target number. After the loop, it simply checks whether the current value equals the input. This straightforward method uses a single integer variable to track the power of four being tested.

<details>
<summary><strong>Why It Works (Click to expand)</strong></summary>
<br>

> At each iteration the variable holds 4^k for some k, so when the loop ends the variable is the smallest power of four that is not less than n. If that power equals n, then n is exactly a power of four; otherwise it cannot be.

</details>

<br>

### Complexity

| Bound | Explanation |
|:--|:--|
| **Time:** `O(log₄ n)` | time, because the loop runs once per exponent of four needed to reach or exceed n. |
| **Space:** `O(1)` | space, only a constant number of variables are used. |

<br>

> [!TIP]
> **Key Insight**
> 
> Keep multiplying by four until you either hit or surpass the target.

<br>

> [!IMPORTANT]
> **Pattern to Remember**
>
> Iterative exponentiation by repeated multiplication.
