> [!NOTE]
> **Problem Statement**
>
> Given a positive integer num, return true if num is a perfect square or false otherwise.
> 
> A perfect square is an integer that is the square of an integer. In other words, it is the product of some integer with itself.
> 
> You must not use any built-in library function, such as sqrt.
> 
>  
> Example 1:
> 
> Input: num = 16
> Output: true
> Explanation: We return true because 4 * 4 = 16 and 4 is an integer.
> 
> 
> Example 2:
> 
> Input: num = 14
> Output: false
> Explanation: We return false because 3.742 * 3.742 = 14 and 3.742 is not an integer.
> 
> 
>  
> Constraints:
> 
> 
> 	1 <= num <= 231 - 1
>
> **[→ Open on LeetCode](https://leetcode.com/problems/valid-perfect-square/)**

<br>

### Solution (C++)

```cpp
class Solution {
public:
    bool isPerfectSquare(long int num) {
        long int i;
        for( i=0;i*i<num;i++){

        }
        if(i*i==num){
            return true;
        } 
        return false;
    }
};
```

<br>

### Approach

> Iterate i from 0 upward, checking i*i against the target number. Stop when i*i is equal to or exceeds the number. If i*i equals the number, return true; otherwise return false.

<details>
<summary><strong>Why It Works (Click to expand)</strong></summary>
<br>

> A perfect square has an integer square root, so the loop will eventually hit that integer where i*i equals the number. If the loop passes the number without equality, no integer square root exists.

</details>

<br>

### Complexity

| Bound | Explanation |
|:--|:--|
| **Time:** `O(sqrt(n)` | ) – the loop runs at most up to the integer square root of n. |
| **Space:** `O(1)` | only a few constant‑size variables are used. |

<br>

> [!TIP]
> **Key Insight**
> 
> A number is a perfect square exactly when its integer square root squared reproduces the original number.

<br>

> [!IMPORTANT]
> **Pattern to Remember**
>
> Search for an integer whose square matches the target; this linear scan up to √n is a common brute‑force pattern for perfect‑square checks.
