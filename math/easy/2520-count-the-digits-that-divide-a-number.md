> [!NOTE]
> **Problem Statement**
>
> Given an integer num, return the number of digits in num that divide num.
> 
> An integer val divides nums if nums % val == 0.
> 
>  
> Example 1:
> 
> Input: num = 7
> Output: 1
> Explanation: 7 divides itself, hence the answer is 1.
> 
> 
> Example 2:
> 
> Input: num = 121
> Output: 2
> Explanation: 121 is divisible by 1, but not 2. Since 1 occurs twice as a digit, we return 2.
> 
> 
> Example 3:
> 
> Input: num = 1248
> Output: 4
> Explanation: 1248 is divisible by all of its digits, hence the answer is 4.
> 
> 
>  
> Constraints:
> 
> 
> 	1 <= num <= 109
> 	num does not contain 0 as one of its digits.
>
> **[→ Open on LeetCode](https://leetcode.com/problems/count-the-digits-that-divide-a-number/)**

<br>

### Solution (C++)

```cpp
class Solution {
public:
    int countDigits(int num) {
        int count=0;
        int updated=num;
        for(int i=1;i<num,updated>0;i++){
            if(num%(updated%10)==0){
                count++;
            }
            updated/=10;
        }
        return count;
    }
};
```

<br>

### Approach

> Iterate through each digit of the given number by repeatedly taking the remainder modulo 10 and then dividing by 10. For each extracted digit, check if the original number is divisible by that digit using the modulo operator. Increment a counter whenever the divisibility condition holds. Return the final counter as the answer.

<details>
<summary><strong>Why It Works (Click to expand)</strong></summary>
<br>

> Each digit is examined exactly once, and the check num % digit == 0 is precisely the definition of a digit dividing the number, so the count accumulates all valid digits. The loop invariant is that all processed lower-order digits have been correctly counted before moving to the next digit.

</details>

### Complexity

| Bound | Explanation |
|:--|:--|
| **Time:** `O(d)` | where d is the number of digits (at most 10 for the given constraints), because we perform a constant‑time operation for each digit. |
| **Space:** `O(1)` | since only a few integer variables are used regardless of input size. |

> [!TIP]
> **Key Insight**
> 
> A number’s digits can be processed independently by stripping them off with modulo and division, allowing a simple divisibility test per digit.

> [!IMPORTANT]
> **Pattern to Remember**
>
> Use the modulo‑10 and divide‑by‑10 pattern to traverse digits of an integer while applying constant‑time checks on each digit.
