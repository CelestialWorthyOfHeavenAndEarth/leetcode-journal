> [!NOTE]
> **Problem Statement**
>
> Given a positive integer num, return the number of positive integers less than or equal to num whose digit sums are even.
> 
> The digit sum of a positive integer is the sum of all its digits.
> 
>  
> Example 1:
> 
> Input: num = 4
> Output: 2
> Explanation:
> The only integers less than or equal to 4 whose digit sums are even are 2 and 4.    
> 
> 
> Example 2:
> 
> Input: num = 30
> Output: 14
> Explanation:
> The 14 integers less than or equal to 30 whose digit sums are even are
> 2, 4, 6, 8, 11, 13, 15, 17, 19, 20, 22, 24, 26, and 28.
> 
> 
>  
> Constraints:
> 
> 
> 	1 <= num <= 1000
>
> **[→ Open on LeetCode](https://leetcode.com/problems/count-integers-with-even-digit-sum/)**

<br>

### Solution (C++)

```cpp
class Solution {
public:
    int countEven(int num) {
        int count = 0;
        for (int i = 1; i <= num; i++) {
            int nums = i;
            int sum = 0;
            while (nums > 0) {
                sum = sum + nums % 10;
                nums = nums / 10;
            }
            if (sum % 2 == 0) {
                count++;
            }
        }
        return count;
    }
};
```

<br>

### Approach

> Iterate through every integer from 1 to num, compute its digit sum by repeatedly taking the remainder modulo 10 and dividing by 10, and increase a counter when the sum is even.

<details>
<summary><strong>Why It Works (Click to expand)</strong></summary>
<br>

> The loop examines each candidate number exactly once and the digit‑sum calculation correctly reflects the definition, so every number with an even digit sum is counted and none are missed.

</details>

### Complexity

| Bound | Explanation |
|:--|:--|
| **Time:** `O(num · d)` | where d is the number of digits of num (at most 4 for the given constraints), because each number’s digits are processed once. |
| **Space:** `O(1)` | because only a few integer variables are used regardless of input size. |

> **Key Insight**
> 
> Even‑digit‑sum numbers can be identified by a straightforward digit‑by‑digit accumulation, making a simple linear scan sufficient for small limits.
