> [!NOTE]
> **Problem Statement**
>
> Given an integer n, return true if n has exactly three positive divisors. Otherwise, return false.
> 
> An integer m is a divisor of n if there exists an integer k such that n = k * m.
> 
>  
> Example 1:
> 
> Input: n = 2
> Output: false
> Explantion: 2 has only two divisors: 1 and 2.
> 
> 
> Example 2:
> 
> Input: n = 4
> Output: true
> Explantion: 4 has three divisors: 1, 2, and 4.
> 
> 
>  
> Constraints:
> 
> 
> 	1 <= n <= 104
>
> **[→ Open on LeetCode](https://leetcode.com/problems/three-divisors/)**

<br>

### Solution (C++)

```cpp
class Solution {
public:
    bool isThree(int n) {
        int count;
        for(int i=1;i<=n;i++){
            if(n%i==0){
                count++;
            }
        }
        if(count==3){
            return true;
        }
        return false;
    }
};
```

<br>

### Approach

> The solution iterates through every integer i from 1 up to n and checks if i divides n without remainder. Each time a divisor is found, a counter is incremented. After the loop finishes, the counter holds the total number of positive divisors of n. The function then returns true if this count equals exactly three, otherwise false.

<details>
<summary><strong>Why It Works (Click to expand)</strong></summary>
<br>

> If a number has exactly three positive divisors, the loop will encounter them and increment the counter three times, making the final count equal to three. Conversely, any number with fewer or more divisors will produce a count different from three, leading the function to return false.

</details>

### Complexity

| Bound | Explanation |
|:--|:--|
| **Time:** `O(n)` | the algorithm examines each integer from 1 to n once, performing a constant‑time modulo operation per iteration. |
| **Space:** `O(1)` | only a few integer variables are used regardless of the input size. |
