> [!NOTE]
> **Problem Statement**
>
> Given a non-empty array of integers nums, every element appears twice except for one. Find that single one.
> 
> You must implement a solution with a linear runtime complexity and use only constant extra space.
> 
>  
> Example 1:
> 
> 
> Input: nums = [2,2,1]
> 
> Output: 1
> 
> 
> Example 2:
> 
> 
> Input: nums = [4,1,2,1,2]
> 
> Output: 4
> 
> 
> Example 3:
> 
> 
> Input: nums = [1]
> 
> Output: 1
> 
> 
>  
> Constraints:
> 
> 
> 	1 <= nums.length <= 3 * 104
> 	-3 * 104 <= nums[i] <= 3 * 104
> 	Each element in the array appears twice except for one element which appears only once.
>
> **[→ Open on LeetCode](https://leetcode.com/problems/single-number/)**

<br>

### Solution (C++)

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ans=0;
        for(int x:nums){
            ans=ans^x;
        }
        return ans;
    }
};
```

<br>

### Approach

> Iterate through the array once, maintaining a running XOR of all elements. The XOR operator has the property that a^a = 0 and a^0 = a, so each pair of identical numbers cancels out. After processing the whole array, the accumulator holds the value that appeared only once. Return this accumulator as the answer.

<details>
<summary><strong>Why It Works (Click to expand)</strong></summary>
<br>

> Because XOR is associative and commutative, the order of processing does not matter; all duplicate elements XOR to zero, leaving only the unique element. This invariant guarantees the final result is exactly the single number.

</details>

<br>

### Complexity

| Bound | Explanation |
|:--|:--|
| **Time:** `O(n)` | each element is visited exactly once during the single pass. |
| **Space:** `O(1)` | only a constant‑size integer variable is used regardless of input size. |

<br>

> [!TIP]
> **Key Insight**
> 
> XORing all numbers eliminates pairs and reveals the lone element.

<br>

> [!IMPORTANT]
> **Pattern to Remember**
>
> Use the XOR reduction pattern to find an element that appears an odd number of times when all others appear an even number of times.
